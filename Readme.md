# 🤖 Telegram Comment Bot

Автоматический бот для комментирования постов в Telegram с использованием AI.

## 📋 Описание

Бот автоматически:
- Отслеживает новые посты в указанном канале
- Генерирует живые комментарии с помощью AI (GPT)
- Отправляет комментарии от имени нескольких аккаунтов
- Может создавать мини-диалоги между аккаунтами
- Поддерживает отправку GIF

## ⚡ Особенности

- 🧠 Использование AI (GPT-4o-mini) для генерации комментариев
- 👥 Поддержка множества аккаунтов
- 🌐 Поддержка прокси (SOCKS5/HTTP)
- 🎭 Разные стили комментариев (скептик, ироничный, хайповый и т.д.)
- 🎬 Отправка случайных GIF
- 💬 Мини-диалоги между аккаунтами
- 📝 Настраиваемые задержки и вероятности
- 🔒 Безопасное хранение данных через .env
